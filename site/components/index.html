Cómo funciona

  1. Elige un componente y ajústalo en el editor en vivo (color, radio, animación). 
    npx webmcpcss components list --library tailwind
  2. Impórtalo: se copian el HTML, el .webmcp.css y component.json a tu proyecto y se registra la versión. 
    npx webmcpcss components import tailwind-button-primary --output ./src/components
  3. Sírvelo a los agentes: el contrato se expone por MCP, por document.modelContext o por la API declarativa de WebMCP. 
    npx webmcpcss mcp --serve --css ./src/components/tailwind-button-primary/button-primary.webmcp.css --hub
  4. Mantenlo al día y comparte los tuyos. 
    npx webmcpcss components update
npx webmcpcss components publish ./mi-boton.webmcp.css --name "Mi botón" --category buttons

Para agentes

Este sitio declara <meta name="webmcp-hub">, JSON-LD y un índice legible por máquinas. Un agente MCP puede descubrir e importar componentes con las herramientas list_components, get_component e import_component del servidor webmcpcss mcp --serve --hub, o leer directamente:
