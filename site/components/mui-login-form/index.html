/* Importar: npx webmcpcss components import mui-login-form */

/* Material UI: el HTML es el DOM que renderizan <TextField> y <Button>; los atributos declarativos van en inputProps. */
/* Contrato WebMCP (equivalente al marcado declarativo del HTML: toolname/tooldescription/toolparamtitle) */
form[data-form="login-form"] button[type="submit"] {
  webmcp-tool: "login";
  webmcp-description: "Inicia sesión con correo y contraseña";
  webmcp-param-email: value(form[data-form="login-form"] [name="email"]);
  webmcp-param-password: value(form[data-form="login-form"] [name="password"]);
  webmcp-trigger: "submit" on form[data-form="login-form"];
  webmcp-intent: "submit";
  webmcp-confirmation: "needed";
  webmcp-permissions: "restricted";
  webmcp-doc-email: "Correo con el que te registraste";
  webmcp-doc-password: "Contraseña de la cuenta (mínimo 8 caracteres)";
}

Cómo usarlo

  1. Importa el componente a tu proyecto (HTML + .webmcp.css + component.json):
    npx webmcpcss components import mui-login-form --output ./src/components
  2. O añade solo el contrato a tu webmcp.css existente (bloque delimitado y actualizable):
    npx webmcpcss components import mui-login-form --merge ./webmcp.css
  3. Publícalo para los agentes: MCP (webmcpcss mcp --serve --css ./webmcp.css), document.modelContext (webmcpcss standard compile ./webmcp.css --html index.html) o exporta a tu agente favorito (webmcpcss export --agent claude-code).

Ejemplos con la CLI

  • cambia el texto del botón Entrar a Acceder

webmcpcss animate — animaciones declarativas

  • haz que el formulario de login aparezca con fade-in
  • agita el formulario cuando falle el acceso
