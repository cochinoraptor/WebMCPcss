Convierte cualquier web en herramientas para agentes de IA

Un archivo .webmcp.css mapea selectores a acciones como addToCart o login. Sin permisos del sitio, con auto-reparación cuando el sitio se rediseña, órdenes en lenguaje natural, animaciones declarativas y, desde la 1.0, permisos, accesibilidad, tests, versionado y pagos declarados en el mismo CSS.

Flujo de trabajo

De cero a agente operando, en tres comandos

CSS estándar con propiedades webmcp-*. Los selectores que ya usas para dar estilo ahora también declaran qué puede hacer un agente.

1

Declara — o deja que se genere

tienda.webmcp.css
/* webmcpcss generate https://tienda.com --auto */
[data-product] .btn-add {
  webmcp-tool: "addToCart";
  webmcp-param-quantity: value(#qty);
  webmcp-confirmation: ".cart-badge";
}

También desde tu código fuente React/Vue/Svelte con --from-source, desde un diseño con design analyze, o desde cero con init --framework ia-first.

2

Sirve por MCP o REST

zsh
# stdio para Claude, Cursor, Goose…
webmcpcss mcp --serve \
  --css tienda.webmcp.css \
  --url https://tienda.com
[webmcpcss] MCP stdio listo · 2 herramientas

El agente lista las herramientas y las ejecuta de verdad con navegador headless.

3

El sitio cambió: se auto-repara

zsh
webmcpcss repair https://tienda.com \
  tienda.webmcp.css
✔ .btn-add → [data-cy="add"]
✔ archivo actualizado (1 reparación)

Modo visión: reencuentra el elemento por huella (texto, atributos, tag) y reescribe el selector.

Capacidades

Todo incluido, cero fricción

TypeScript estricto, arquitectura modular y una CLI que cubre el ciclo completo: generar → validar → reparar → exportar → servir.

⚡

Generación automática

generate --auto escanea la página sin grabar nada: formularios, botones, campos. Detecta el framework (React, Vue, Svelte, Angular, Tailwind…) y elige selectores estables.

🧩

Desde el código fuente

generate --from-source analiza componentes JSX/Vue/Svelte sin navegador ni deploy, y avisa qué elementos necesitan data-tool. Úsalo como linter en CI.

🔌

Servidor MCP real

stdio JSON-RPC para Claude Desktop/Code, Cursor, Goose, Windsurf… y modo REST (/api/tools, /api/call) con ejecución real vía navegador.

📤

10 exportadores v0.9

Plugin Claude Code (comandos + skill), Cursor (snippets y regla), CrewAI, AutoGen, LangGraph, DeerFlow, Flomny, JSON Schema, browser-inject (window.__WEBMCP_GRAPH__) y config MCP universal.

🩹

Auto-reparación

Selectores rotos tras un rediseño se reencuentran por fingerprint y el archivo se actualiza solo. Con análisis de fragilidad: hashes CSS-Modules, Vue scoped, styled-components…

🕸️

Grafo + Obsidian v0.9

Tu tool map como grafo de conocimiento navegable, dashboard Cytoscape con filtros por framework y exportación PNG/SVG/JSON, y bóveda Obsidian portable. Detecta el framework de cada selector frágil (CSS Modules, Vue scoped, styled-components…).

💬

Lenguaje natural v0.7

webmcpcss prompt "oculta el popup de cookies" interpreta la orden (con o sin LLM), localiza el elemento y la ejecuta con evidencia. También como herramienta MCP webmcpcss_prompt.

🎬

Animaciones declarativas v0.8

Parallax, isométrico, 3D, keyframes y escenas Three.js declaradas con webmcp-animation-*. Motor CSS / WAAPI / WebGL elegido por capacidades, resolución de conflictos con GSAP, Anime.js o Framer Motion y validate-conflicts para CI.

📊

Historial + dashboard

Cada ejecución, reparación, prompt o animación queda registrada. webmcpcss dashboard abre un panel local con métricas, fragilidad de selectores y el grafo del sitio.

Lenguaje natural · v0.7

Dile al sitio qué hacer, en tu idioma

webmcpcss prompt traduce órdenes en español o inglés a acciones estructuradas, localiza el elemento de forma progresiva y las ejecuta sobre la página con captura de evidencia. Funciona sin LLM; mejora con Ollama, OpenAI o Anthropic.

zsh
webmcpcss prompt "pon la cantidad en 3 y aplica el cupón VERANO" \
  --url https://tienda.com --css tienda.webmcp.css --execute
ℹ Acción: fill → cantidad [heuristic, confianza 0.92]
ℹ Elemento: #qty (vía label, 0.95)
✔ Valor "3" establecido en #qty
ℹ Acción: click → cupón · herramienta applyCoupon
✔ applyCoupon ejecutada (confirmación .coupon-ok visible)
ℹ Captura: despues.png
selector→herramienta .webmcp.css→LLM→texto / label→visión→sondas
  • 10 acciones: upload, changeColor, delete, move, click, fill, hide, setText, setStyle, other.
  • Dry-run por defecto: sin --execute solo muestra lo que haría.
  • Si el elemento pertenece a una herramienta declarada, la acción se delega en ella (con auto-reparación incluida).
  • Herramienta MCP webmcpcss_prompt y POST /api/prompt para que cualquier agente la use.
  • Lista blanca de estilos, validación de colores/URLs/archivos e historial de cada acción.

Animaciones · v0.8 – v0.9

Animaciones declaradas en CSS, ejecutadas por agentes

Parallax, isométrico, transformaciones 3D, keyframes y escenas 2.5D con Three.js, descritas con propiedades webmcp-animation-*. El orquestador elige el motor (CSS, WAAPI o WebGL) según el navegador y nunca pisa las animaciones que el sitio ya tiene.

3d-transformrotateY · perspective 900px
5 executed · css
↕ haz scroll · ↔ mueve el ratón

Demo en vivo con la misma lógica del motor CSS: capas a distinta velocidad de scroll y una tarjeta 3D que sigue al puntero. En tu sitio lo declara el archivo de la derecha.

animations.webmcp.css
#hero {
  webmcp-animation: "heroParallax";
  webmcp-animation-type: parallax;
  webmcp-animation-layers:
    ".sky" 0.1, ".mountains" 0.5, ".ground" 0.8;
}
#card {
  webmcp-animation: "flipCard";
  webmcp-animation-type: 3d-transform;
  webmcp-animation-perspective: 900px;
  webmcp-animation-rotation-y: 25deg;
  webmcp-animation-conflict: queue; /* respeta GSAP */
}
#badge {
  webmcp-animation: "badgePop";
  webmcp-animation-priority: critical; /* sustituye */
  webmcp-animation-keyframes:
    '[{"transform":"scale(1)"},
      {"transform":"scale(1.15)"}]';
}
#scene {
  webmcp-animation: "depth";
  webmcp-animation-type: three-scene;
  webmcp-animation-sandbox: shadow;
  webmcp-animation-fallback: "heroParallax";
}

$ webmcpcss animate animations.webmcp.css --url https://tienda.com
✔ badgePop     waapi  (sustituyendo css:sitePulse)
✔ heroParallax css    3 capas
⊘ flipCard     ignorada · conflicto con gsap@wa7
✔ depth        three  sandbox shadow · WebGL

parallax

Capas con velocidad 0–1 y profundidad. CSS por scroll, ScrollTimeline o escena WebGL.

isometric

rotateX/rotateZ con preserve-3d. Tarjetas, mapas y cuadrículas.

3d-transform

Perspectiva, rotaciones, translateZ y escala compuestas; fusión con composite: add.

keyframes

Fotogramas arbitrarios por WAAPI o @keyframes inyectados.

three-scene

Planos 2.5D que siguen ratón y scroll. Three.js solo si se usa; fallback sin WebGL.

  • Prioridades low → critical y estrategias replace, queue, ignore, merge.
  • Detecta GSAP, Anime.js, Framer Motion, Velocity, Lottie, AOS y las animaciones CSS/WAAPI del sitio; registerExternal() para las tuyas.
  • --dry-run con informe de conflictos previstos, fallback por animación y respeto de prefers-reduced-motion.
  • Herramienta MCP webmcpcss_animate, POST /api/animate y runtime de 85 KB para incluir en tu web.
  • v0.9validate-conflicts anim.webmcp.css --url … --strict simula en seco los conflictos con las animaciones del sitio; animate --sandbox las aísla en un shadow root.
