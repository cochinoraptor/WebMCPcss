Referencia rápida de la CLI

webmcpcss components list [--category <cat>] [--library <lib>] [--search <texto>] [--json]
webmcpcss components import <id...> [--output <dir>] [--merge <archivo.css>] [--force]
webmcpcss components update [id...] [--dry-run]
webmcpcss components demo [--output <dir>] [--library <lib>]
webmcpcss components publish <archivo.webmcp.css> --name "Nombre" --category <cat> [--library <lib>] [--html <archivo>]
webmcpcss mcp --serve --hub   # añade list_components / get_component / import_component
